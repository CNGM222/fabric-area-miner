# Area Miner（Minecraft 1.21.11 / Fabric）

这是一个**仅客户端** Fabric mod：依次选定两个方块作为长方体区域的角点，显示区域线框，然后通过客户端交互管理器逐块挖掘；不会添加服务端代码、执行命令或直接修改世界方块。

## 默认按键

- **Z**：循环设置角点 1、角点 2。先把准星对准方块再按；选区包含两个端点方块。
- **F8**：开始/停止。正在运行时按 F8 会停止；全部完成、切换维度或玩家死亡时会自动停止。
- 两个按键均可在 Minecraft「选项 → 控制 → 按键绑定 → 区域挖掘」中修改。

选区用青色框显示，当前正在处理的方块以橙色框标出。

## 工作方式

1. **挑目标**：每处理完一格就重新计算一次，**按距离从近到远**（从玩家脚部量起）。取最近的、能挖的方块：「当前视线能直接打到」或「暴露在表面上」（六个相邻方向中至少有一个是空气/流体/可替换方块）。因此会先把脚下周围一圈清干净再往外推进，不会去够埋在实心方块中间的格子。正在站立的支撑方块有额外惩罚，避免一脚踩空。
2. **走过去**：目标不在交互距离内时，用 A* 在可站立的地面格上寻路（4 方向，可上 1 格台阶、可下坠最多 3 格），然后按住前进键沿着路点走，需要上台阶时自动起跳。路点必须**人真的站在那一格的高度**才算走完（`|dy| < 0.5`）：上下都不再提前算到达 —— 站在地毯/雪层上时脚会高 1/16，旧版本会把上一格台阶、或下一格落点误判成「已到达」，于是不起跳、也不往下走，原地顶着不动。卡住 1.5 秒会触发一次起跳冲刺并重新规划，连续两次仍无进展就跳过该方块并在动作栏提示。走路时会临时接管前进/跳跃键，停止或到达后恢复原状态。
3. **挖掘**：把准星转向该方块的**实际命中点**，再用 `attackBlock` / `updateBlockBreakingProgress` 走普通左键挖掘流程，并等待射线真的落在该方块上。客户端预测挖掉的方块**不会立刻从任务列表里删掉**：会再观察约 4 秒，服务器把方块回溯回来（延迟、保护、预测被纠正）就重新排队再挖；挖完整个选区后还会对选区做一次复查，把漏掉的方块捡回来继续挖，而不是直接报「完成」。
4. **工具**：**每换一个方块都重新选一次工具**，选择快捷栏里对该方块「原版挖掘速度最快」的那个（直接调用 `PlayerEntity.getBlockBreakingSpeed`，所以工具等级、效率附魔、急迫效果都与手动切换一致）；即将损坏的工具会被跳过。硬度 ≤ 0.15 的方块（地毯、雪层、花、火把等）本来就是几下就碎，会切到**空手或非工具物品**去挖：既不浪费耐久，也避免出现「为地毯换上剪刀/锄头，下一个石头还拿着它慢慢敲」的情况。由于仍走正常交互调用，Fabric 的 `AttackBlockCallback` 照常触发。

单个方块连续 3 秒没有任何破坏进度（例如领地保护、工具不足）会被跳过并继续处理下一个，而不是整个任务卡住；所有剩余方块都到不了时才会停止并提示。如果人既没有移动、也没有挖掉方块超过 3 秒，动作栏会显示「区域挖掘等待中：目标 …，剩余 … 格」，方便判断它卡在哪个方块上。

## 方块形状

命中判定使用方块的 **outline 形状**（不是整个 1×1×1 立方体），并在形状内部取样点做射线检测，因此：

- 地毯、雪层、台阶、按钮、花盆等非整方块可以被正确选中和挖掘；
- 可站立判定允许脚部与地毯、雪层这类高度 ≤ 0.6 的薄方块重叠，所以能正常走过铺了地毯的地面。

## 移动与安全边界

- 最大选区体积：32,768 格；开始前会检查选区覆盖的所有区块已加载。
- 寻路上限：6000 个节点、每次约 25 ms；路点连续 50 tick 无进展会重新规划，连续 3 次失败则跳过该方块。
- 不挖空气、流体和硬度为负的方块。
- 不会挖选区以外的方块来开路，不会搭桥、游泳、爬墙或跳过 2 格以上的落差；路线不存在时会停止而不是绕路。
- 远距离按地面路径前进，不支持飞行、船/矿车等交通方式。
- 自动移动会暂时占用前进/跳跃键；请勿在移动过程中离开游戏或进入危险地形。
- 多人服务器可能禁止自动化操作；请先确认服务器规则。客户端模组不绕过服务器权限、领地保护或游戏模式限制。

## 构建

需要 JDK 21 或更新版本、Gradle 9.0 或更新版本，并能访问 Fabric Maven 与 Mojang 下载站点：

```powershell
gradle build
```

产物位于 `build/libs/`。将 remapped jar 放入客户端实例的 `mods` 文件夹，并安装相同 Minecraft 版本的 Fabric Loader 及 Fabric API。项目版本固定为 Minecraft 1.21.11、Yarn build 6、Fabric Loader 0.20.1、Fabric API 0.141.6+1.21.11。

## Release

推送 `v*` tag 会触发 GitHub Actions 构建；只有构建成功后才会创建 GitHub release 并附上 remapped mod jar。工作流使用 JDK 21 和 Gradle 9.0。

**Release 说明取自 `CHANGELOG.md` 中对应版本的小节**（`## 1.1.3` 这样的标题），所以发版前先在 `CHANGELOG.md` 里写好这一版改了什么；找不到小节时会退化成一句指向 `CHANGELOG.md` 的提示。
